# GXR Annotate

A live annotation layer for Kineviz GraphXR / Kineviz Desktop — annotate the canvas **in place**, save per view, present without exporting. Current: **v0.6.0**.

**Old workflow:** create view → export → image editor → annotate → re-export.
**Now:** create view → annotate on the live canvas → present (tour) or export.

## What's in the box

- **`annotate-overlay.js`** — the layer (single file, framework-free, injected into the app window). Three anchor classes: node-derived marks (callouts with leader lines, cluster circles, node-snapped arrows — they follow the data through layout re-runs), free graph-space marks (glued through pan/zoom), and screen-fixed view titles. Per-view persistence via a merge-safe project sidecar (`gxr.files`), tour mode with camera fly + captioned HUD, global display scale, GraphXR-dark-theme UI. Interaction policy: **draw mode off = the layer is glass** (camera gestures can never touch marks).
- **`grovebook/GXR Annotate Showcase.md`** — the demo/entry book (generated by `build-showcase.js`): installs the layer, seeds a 3-community graph, one click builds sample annotations on a saved view.
- **`grovebook/GXR Annotate Layer.md`** — minimal bootstrap book for real projects (generated by `build-layer-grovebook.js`).
- **`annotate-core.js` + `standalone/`** — the v0.2 screenshot-capture editor (kept for freehand/pixel markup) and its browser test harness.

## Install in a project

1. Copy the book into the project's grove files (Grove panel → FILES, or drop the `.md` into `tmp/files/<projectId>/groves/`).
2. Open it, run the cells. The floating toolbar survives closing the panel.
3. Optional — pin it to the left toolbar via `POST /api/grovePinned/add` with an accessPath that **must include `bookId=files`** (without it, Grove ≥ 2.0.37 boots the legacy observable tree and the book appears empty; see graphxr `modules/grovePinned/normalize-access-path.ts`).

## Develop

```bash
node build-showcase.js          # regenerate the showcase book after editing annotate-overlay.js
node build-layer-grovebook.js   # regenerate the minimal bootstrap book
```

No backticks allowed in `annotate-overlay.js` (it is embedded inside a grovebook cell via Function.toString).
