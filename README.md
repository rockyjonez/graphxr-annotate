# GXR Annotate

Annotate GraphXR canvas views **inside Kineviz Desktop** — capture, mark up, export. No external image editor.

**Old workflow:** create view → export → import into image editor → annotate → export again.
**New workflow:** create view → annotate → export. Done.

## How it works

- `annotate-core.js` — framework-free annotation editor (SVG overlay over a captured image). Tools: arrow, box, ellipse, pen, highlighter, text (auto-outlined), numbered step badges. Select/move/reshape, undo/redo, restyle-on-select. Exports PNG (download or clipboard) at native capture resolution, plus re-editable SVG with the image embedded.
- `grovebook/GXR Annotate.md` — the deliverable: a grovebook that runs inside any Kineviz Desktop / GraphXR project. It captures the current canvas with `gxr.screenshot()` (camera untouched) and mounts the editor right in the Grove panel. Generated by `build-grovebook.js` — **do not edit by hand**.
- `standalone/index.html` — test harness with a synthetic graph canvas; no GraphXR needed.

## Install (Kineviz Desktop)

1. Open your project → Grove panel → FILES.
2. Add `grovebook/GXR Annotate.md` to the project's grove files.
3. Open it, arrange your canvas, hit **📸 Capture current canvas view**, annotate, **Export PNG** (or **Copy PNG** → paste into your deck).

## Develop

```bash
node build-grovebook.js   # regenerate the grovebook after editing annotate-core.js
python3 -m http.server 8123   # then open /standalone/index.html
```
